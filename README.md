# 渐近自由：个人物理博客

AsyaInTheCosmicStatic 的中文理论物理博客：从模型出发，向结构深入。首页保持极简，正文采用纸刊式三栏阅读。

> Agent 在维护或发布前必须完整阅读根目录的 `AGENTS.md`。文章合同、视觉边界、发布流程和验收标准均以该文件为准。

## 日常写作

长期写作和修订优先在 `%USERPROFILE%\Obsidian\reading-essays\<学科>\notes\` 中完成；学科明确时放进对应学科，而不是统一堆到根目录。`content/` 保存网站实际构建使用的发布副本。

用户只需要在 Obsidian 修改源稿并告诉 Codex“发布这篇”或“重新上传这篇”；Codex 负责按 `blog_id` 同步发布副本、转换 WikiLink 和附件、补全网站元数据、检查公式与图片、构建、提交与推送。`templates/article.md` 是网站侧结构参考，不要求用户手工填写。

## 本地检查

博客的日常工程目录统一为 `%USERPROFILE%\Obsidian\个人博客`。维护前核对远端最新成功部署版本；不要使用历史发布 worktree 作为基线。

书房音乐包含 9 首曲目，使用独立展示名并保留来源链接。支持进度拖动、歌单点选、上一首/下一首、顺序播放、列表循环、单曲循环、随机播放、静音、音量记忆、曲目与进度恢复、定时停止及浏览器系统媒体控制。站内首页、文章、笔记及搜索之间切换时连续播放；刷新页面后保持暂停，首次点击播放才加载音频。随机播放每轮不重复，上一首优先返回实际播放历史；播放超过 3 秒时先回到本曲开头。定时停止跨站内页面保留，优先于循环模式；刷新页面会取消定时。

音频来源、时长和 SHA-256 记录于 `docs/music-sources.json`；执行 `node scripts/check-music-playlist.mjs` 检查播放模式、进度恢复和定时停止逻辑。

## 公式工具

正常阅读时隐藏逐公式操作文字。桌面悬停或键盘聚焦出现 `⋯`，点击打开全篇共用的菜单；手机先在文章顶部开启“公式工具”，再轻点公式。横滑和长按选择保留。菜单不占正文高度，支持复制原始 LaTeX、稳定公式链接及手动复制降级；打印隐藏全部操作。

## 长文章的交互性能

`src/styles/article-performance.css` 为独立公式使用零位移二维变换，缩小 Edge 鼠标命中检测的遍历开销；正文保持完整、即时排版，打印取消该变换。不要将它改成 `translateZ(0)`、`will-change` 或逐公式动态隐藏：强制 GPU 合成及滚动中改变公式高度需要重新做持续交互验证。

阅读进度在支持的浏览器中使用文章范围的原生 View Timeline，不注册 JavaScript 滚动监听。脚本检查实际生效的样式，缺失时回退到按动画帧合并的普通进度计算，不使用 ResizeObserver。动画保持长属性写法，避免压缩工具生成 Edge 尚不识别的含时间线动画简写。

修改这部分后，构建成功不等于性能验收通过。必须在带窗口、启用实际显卡的 Edge 中检查鼠标经过首屏和公式区域、连续往返滚动及停止后的开销；验证最终构建中的进度条在文章顶部/中间/末尾分别为 0/50/100%，并比较桌面、手机、深浅色和打印中的公式内容与位置。无浏览器 API 支持和样式未生效的回退路径也要检查。不得仅用首次加载耗时声称已解决鼠标卡顿。

`node scripts/check-article-interaction.mjs` 可验证构建产物的原生/回退进度、手机/桌面、公式保留、锚点、查找及打印。它使用机器上已有的 Edge 和 Playwright，不自动安装或下载；Playwright 未在当前环境解析路径中时，设置 `PLAYWRIGHT_MODULE` 为外部已安装包目录，浏览器位置可由 `EDGE_EXECUTABLE` 指定。这个功能回归检查不能替代持续交互性能对照。
